Let a, b, c be elements of Nat.
Then a + b + c = a + (b + c).

Proof.
Proceed by induction on c.
  a + b + c = a + (b + c)
  Base case (zero). By reflexivity, a + b + 0 = a + b + 0.
  Successor step. Let c ∈ Nat be arbitrary.
  Assume a + b + c = a + (b + c).
  Apply Nat.succ to both sides of the supplied equality.
    ((a + b).add c).succ = (a.add (b.add c)).succ
    Use the hypothesis ih: a + b + c = a + (b + c).

Leanglish · BatchAcceptance.Lists.append_empty

Let α be a type.
Let xs be an element of List α.
Then xs ++ [] = xs.

Proof.
Proceed by induction on xs.
  xs ++ [] = xs
  Empty-list case. By reflexivity, [] ++ [] = [] ++ [].
  Constructor step. Let x ∈ α be arbitrary.
  Let xs ∈ List α be arbitrary.
  Assume xs ++ [] = xs.
  Apply List.cons x to both sides of the supplied equality.
    x :: xs.append [] = x :: xs
    Use the hypothesis ih: xs ++ [] = xs.

Let α be a type.
Let β be a type.
Let f be an element of α → β.
Let xs, ys be elements of List α.
Then List.map f (xs ++ ys) = List.map f xs ++ List.map f ys.

Proof.
Proceed by induction on xs.
  List.map f (xs ++ ys) = List.map f xs ++ List.map f ys
  Empty-list case. By reflexivity, List.map f ([] ++ ys) = List.map f ([] ++ ys).
  Constructor step. Let x ∈ α be arbitrary.
  Let xs ∈ List α be arbitrary.
  Assume List.map f (xs ++ ys) = List.map f xs ++ List.map f ys.
  Apply List.cons (f x) to both sides of the supplied equality.
    f x :: List.map f (xs.append ys) = f x :: (List.map f xs).append (List.map f ys)
    Use the hypothesis ih: List.map f (xs ++ ys) = List.map f xs ++ List.map f ys.

Let P be a proposition.
Let Q be a proposition.
Let R be a proposition.
Assume P ∨ Q.
Assume P → R.
Assume Q → R.
Then R.

Proof.
Use the intermediate claim h = h → R. Apply it to the additional premises shown below.
  R
  Reason by cases from P ∨ Q.
    Use the hypothesis h: P ∨ Q.
    Case P.
      Assume h = ⋯.
      Apply the hypothesis hp: P → R.
        R
        Use the hypothesis p: P.
    Case Q.
      Assume h = ⋯.
      Apply the hypothesis hq: Q → R.
        R
        Use the hypothesis q: Q.
  By reflexivity, h = h.
    Use the hypothesis h: P ∨ Q.
