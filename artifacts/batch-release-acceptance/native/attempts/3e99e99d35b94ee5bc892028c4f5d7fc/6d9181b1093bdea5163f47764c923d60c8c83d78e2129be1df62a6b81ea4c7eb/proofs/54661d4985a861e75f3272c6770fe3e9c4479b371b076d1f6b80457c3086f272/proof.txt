Let n, m be elements of Nat.
Then 0 + n = n.

Proof.
Use the intermediate claim ∀ (_z : Nat), 0 + n = n. Specialize its object arguments to m.
  0 + n = n
  Proceed by induction on n.
    ∀ (_z : Nat), 0 + n = n
    Base case (zero). Let _z ∈ Nat be arbitrary.
    By reflexivity, 0 + Nat.zero = 0 + Nat.zero.
    Successor step. Let k ∈ Nat be arbitrary.
    Assume ∀ (_z : Nat), 0 + k = k.
    Let z ∈ Nat be arbitrary.
    Apply Nat.succ to both sides of the supplied equality.
      (Nat.add 0 k).succ = k.succ
      Apply the hypothesis ih: ∀ (_z : Nat), 0 + k = k. Substitute z for its object arguments.
        0 + k = k
