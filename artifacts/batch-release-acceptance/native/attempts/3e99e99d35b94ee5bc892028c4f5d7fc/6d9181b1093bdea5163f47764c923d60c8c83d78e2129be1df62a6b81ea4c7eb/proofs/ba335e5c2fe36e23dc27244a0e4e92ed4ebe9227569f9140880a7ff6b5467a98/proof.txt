Let n be an element of Nat.
Then 0 + n = n.

Proof.
Proceed by induction on n.
  0 + n = n
  Base case (zero). By reflexivity, 0 + 0 = 0 + 0.
  Successor step. Let n ∈ Nat be arbitrary.
  Assume 0 + n = n.
  Apply Nat.succ to both sides of the supplied equality.
    (Nat.add 0 n).succ = n.succ
    Use the hypothesis ih: 0 + n = n.
