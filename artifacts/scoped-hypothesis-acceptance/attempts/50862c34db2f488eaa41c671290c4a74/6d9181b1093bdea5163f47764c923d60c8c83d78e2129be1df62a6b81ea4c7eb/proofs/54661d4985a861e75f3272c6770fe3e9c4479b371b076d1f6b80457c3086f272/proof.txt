Leanglish · BatchAcceptance.Induction.rec_overapplied

Let n, m be elements of Nat.
Then 0 + n = n.

Proof.
Apply Nat.rec to the supplied arguments.
  0 + n = n
  Let _z ∈ Nat be arbitrary.
  Apply rfl to the supplied arguments.
    0 + Nat.zero = 0 + Nat.zero
  Let k ∈ Nat be arbitrary.
  Assume ∀ (_z : Nat), 0 + k = k.
  Let z ∈ Nat be arbitrary.
  Apply Nat.succ to both sides of the supplied equality.
    (Nat.add 0 k).succ = k.succ
    Apply the hypothesis ih: ∀ (_z : Nat), 0 + k = k. Substitute z for its object arguments.
      0 + k = k
