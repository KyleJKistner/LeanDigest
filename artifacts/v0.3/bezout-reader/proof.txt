Bézout-frame construction

Let R be a Euclidean domain.
Let x, y, z be elements of R.
Assume x · y = z · (z + 1).
Then ∃ a d b c, a · b = x ∧ d · c = y ∧ d · b = z ∧ a · c − d · b = 1.

Proof.
Set g = gcd(x, z).
Consider the following cases.
  Case g = 0.
    Establish x = 0 ∧ z = 0; call this fact hxz.
      Apply the forward direction of the stated equivalence to the supplied hypothesis.
        x = 0 ∧ z = 0
        A gcd is zero exactly when both entries are zero.
          gcd(x, z) = 0 ↔ x = 0 ∧ z = 0
        Use the hypothesis hg: g = 0.
    Take (a, d, b, c) = (1, y, 0, 1).
    Verify the 4 required conclusions.
      Using x = 0, expand and collect terms.
        1 · 0 = x
      Expand and collect terms.
        y · 1 = y
      Using z = 0, expand and collect terms.
        y · 0 = z
      Expand and collect terms.
        1 · 1 − y · 0 = 1
  Case g ≠ 0.
    Since gcd(x, z) ∣ x, choose a ∈ R with x = gcd(x, z) · a.
      The gcd divides its first entry.
        gcd(x, z) ∣ x
    Since gcd(x, z) ∣ z, choose d ∈ R with z = gcd(x, z) · d.
      The gcd divides its second entry.
        gcd(x, z) ∣ z
    Use the same hypothesis in the form x = g · a.
      Use the hypothesis ha: x = gcd(x, z) · a.
    Use the same hypothesis in the form z = g · d.
      Use the hypothesis hd: z = gcd(x, z) · d.
    Set r = gcdA(x, z). This is the first Bézout coefficient.
    Set s = gcdB(x, z). This is the second Bézout coefficient.
    Establish a · r + d · s = 1; call this fact hbez.
      Cancel the nonzero common factor g to obtain a · r + d · s = 1.
        Use left cancellation away from zero.
          R is a ring with left cancellation away from zero
          In an integral domain, multiplication by a nonzero element is cancellative.
            R is a ring with cancellation away from zero
            A Euclidean domain is an integral domain.
              R is an integral domain
        Use the hypothesis hg: g ≠ 0.
        The following calculation gives g · (a · r + d · s) = g · 1.
          Using x = g · a and z = g · d, expand and collect terms.
            g · (a · r + d · s) = x · r + z · s
          Reverse the supplied equality.
            x · gcdA(x, z) + z · gcdB(x, z) = gcd(x, z)
            Use the Bézout identity supplied by the extended Euclidean algorithm.
              gcd(x, z) = x · gcdA(x, z) + z · gcdB(x, z)
          Reverse the supplied equality.
            g = g · 1
            Multiplication by one leaves the element unchanged.
              g · 1 = g
    Establish a · y = d · (z + 1); call this fact hrel.
      Cancel the nonzero common factor g to obtain a · y = d · (z + 1).
        Use left cancellation away from zero.
          R is a ring with left cancellation away from zero
          In an integral domain, multiplication by a nonzero element is cancellative.
            R is a ring with cancellation away from zero
            A Euclidean domain is an integral domain.
              R is an integral domain
        Use the hypothesis hg: g ≠ 0.
        The following calculation gives g · (a · y) = g · (d · (z + 1)).
          Using x = g · a, expand and collect terms.
            g · (a · y) = x · y
          Use the hypothesis h: x · y = z · (z + 1).
          Using z = g · d, expand and collect terms.
            z · (z + 1) = g · (d · (z + 1))
    Take (a, d, b, c) = (a, d, g, r · (z + 1) + s · y).
    Verify the 4 required conclusions.
      Using x = g · a, expand and collect terms.
        a · g = x
      The following calculation gives d · (r · (z + 1) + s · y) = y.
        Expand and collect terms.
          d · (r · (z + 1) + s · y) = r · (d · (z + 1)) + d · s · y
        Using a · y = d · (z + 1), expand and collect terms.
          r · (d · (z + 1)) + d · s · y = r · (a · y) + d · s · y
        Expand and collect terms.
          r · (a · y) + d · s · y = (a · r + d · s) · y
        Using a · r + d · s = 1, expand and collect terms.
          (a · r + d · s) · y = y
      Using z = g · d, expand and collect terms.
        d · g = z
      The following calculation gives a · (r · (z + 1) + s · y) − d · g = 1.
        Using z = g · d, expand and collect terms.
          a · (r · (z + 1) + s · y) − d · g = a · r · (z + 1) + s · (a · y) − z
        Using a · y = d · (z + 1), expand and collect terms.
          a · r · (z + 1) + s · (a · y) − z = (a · r + d · s) · (z + 1) − z
        Using a · r + d · s = 1, expand and collect terms.
          (a · r + d · s) · (z + 1) − z = 1
