Let n be an element of Nat.
Then 0 + n = n.

Proof.
Proceed by induction on fun k => 0 + k = k.
  0 + n = n
  Base case (zero). By reflexivity, 0 + Nat.zero = 0 + Nat.zero.
  Successor step. Let k ∈ Nat be arbitrary.
  Assume 0 + k = k.
  Apply Nat.succ to both sides of the supplied equality.
    (Nat.add 0 k).succ = k.succ
    Use the hypothesis ih: 0 + k = k.
