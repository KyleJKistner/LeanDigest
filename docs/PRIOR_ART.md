# Relevant prior work

These are reference points, not dependencies. This project does not claim to
invent deterministic verbalization, expandable proof views, controlled natural
language or reversible intermediate formalisms.

- Patrick Massot and Tom Miller, LeanInformal / natural-language generation for
  Lean proofs: https://www.mathinstitutes.org/videos/23068 and
  https://lsd.ucsc.edu/lsd-seminar/2023sp/
- Informath, grammar-based symbolic mathematical informalization:
  https://github.com/aarneranta/informath and
  https://arxiv.org/html/2606.16893v2
- Verbose Lean, controlled-natural-language Lean proof authoring:
  https://github.com/PatrickMassot/verbose-lean4
- Lean elaboration and kernel documentation:
  https://lean-lang.org/doc/reference/latest/Elaboration-and-Compilation/
- Lean source used to confirm exporter interfaces:
  https://github.com/leanprover/lean4/blob/v4.34.1/src/Lean/Util/CollectAxioms.lean
- Lean CI action documentation:
  https://github.com/leanprover/lean-action

The development goal is a complete, testable reading product with explicit
fidelity and coverage claims. A proposed architecture alone is not a research
novelty result. No comparison experiment against these tools has been run.
