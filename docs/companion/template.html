BÉZOUT FRAME · A SUPPORTING THEOREM

A determinant-one frame
from a single equation.

The relation xy = z(z + 1) contains exactly the compatibility needed to construct four entries with determinant one. The proof is a Bézout identity, two justified cancellations, and four explicit checks.

What the evidence establishes
THEOREM

The Bézout frame

Let R be a Euclidean domain, and let x, y, z ∈ R satisfy

xy = z(z + 1).

Then there exist a, d, b, c ∈ R such that

ab = x
dc = y
db = z
ac − db = 1
M = [[a, d], [b, c]], det M = ac − db = 1.

The order of the entries matches the source witnesses (a, d, b, c). The three prescribed products recover (x, y, z).

No assumption says that x, y, z are nonzero. The ring need not be a field and has no assumed ordering.

The facts the proof uses

Standard Euclidean-domain facts
Euclidean domainThe setting

A commutative integral domain with Euclidean division. The proof uses its gcd, Bézout coefficients, and cancellation of a nonzero factor. The integers and the polynomial ring K[t] over a field are familiar examples.

Gcd and Bézout coefficientsThe construction

For g = gcd(x, z), the element g divides both x and z. There are r, s ∈ R with xr + zs = g. Also, g = 0 iff x = z = 0. No positive or monic normalization is required by this argument.

Source names: gcd_dvd_left, gcd_dvd_right, gcd_eq_gcd_ab, gcd_eq_zero_iff.

Nonzero cancellationUsed twice

In an integral domain, g ≠ 0 and gu = gv imply u = v. This does not require an inverse for g. The proof treats g = 0 separately before either cancellation.

Source name: mul_left_cancel₀.

A COMPLETE ARGUMENT

Six steps, with the algebra visible.

The following prose is a curated explanation of the retained theorem body. Its source correspondence has been reviewed; the English has not been formally certified.

01

THE EXCEPTIONAL CASE

Separate the zero case.

Set g = gcd(x, z). If g = 0, the gcd-zero criterion gives x = z = 0. Choose

(a, d, b, c) = (1, y, 0, 1).

All four conclusions are then immediate:

ab = 0 = x; dc = y; db = 0 = z; ac − db = 1.

This finishes the zero case. For every remaining step, assume g ≠ 0.

02

BÉZOUT + THE FIRST CANCELLATION

Normalize the Bézout identity.

Since g divides both inputs, choose a, d ∈ R with x = ga and z = gd. Let r, s be Bézout coefficients, so xr + zs = g. Substitution gives

g(ar + ds) = xr + zs = g = g · 1.

Cancel the nonzero factor g. The normalized pair now has the useful relation

ar + ds = 1.
Bézout relation
03

THE GIVEN EQUATION + THE SECOND CANCELLATION

Transfer the original relation.

Use the hypothesis xy = z(z + 1), together with x = ga and z = gd:

g(ay) = xy = z(z + 1) = g(d(z + 1)).

Cancel the nonzero factor g again. This yields the compatibility relation that will make the remaining entry work:

ay = d(z + 1).
Transferred relation
04

THE CONSTRUCTION

Choose the remaining entries.

Keep the a, d already chosen, and set

b = g, c = r(z + 1) + sy.

The first prescribed product follows directly from x = ga and commutativity:

ab = ag = ga = x.
05

TWO MORE PRODUCT CHECKS

Recover the other two products.

Expand dc, use d(z + 1) = ay, and collect the terms with the Bézout relation:

dc = d(r(z + 1) + sy) = r·d(z + 1) + dsy = r(ay) + dsy = (ar + ds)y = y.

The third prescribed product is immediate from z = gd:

db = dg = gd = z.
06

THE DETERMINANT CHECK

The determinant is exactly one.

Finally, substitute the chosen c, use db = z, and then apply the two relations established above:

ac − db = a(r(z + 1) + sy) − dg = ar(z + 1) + s(ay) − z = (ar + ds)(z + 1) − z = (z + 1) − z = 1.

The same four witnesses satisfy every required equality, completing the proof. □

WHY THIS FITS

The equation is the compatibility condition.

If the required entries already existed, then ac − db = 1 and db = z would give ac = z + 1. Commutativity would force

xy = (ab)(dc) = (ac)(db) = (z + 1)z.

The theorem shows that, over a Euclidean domain, this necessary relation is also sufficient. This paragraph explains the construction’s motivation; it is not an additional claim about the full affine-cancellation paper.
