A Bézout frame

Let [[R]] be a Euclidean domain and let [[x,y,z∈R]] satisfy [[xy=z(z+1)]]. There are [[a,d,b,c∈R]] such that

[[ab=x, dc=y, db=z, ac−db=1.]]

Construction

First suppose [[g=gcd(x,z)≠0]]. Write [[x=ga]] and [[z=gd]], and take [[b=g]]. The remaining requirements are

[[ac=z+1, dc=y.]]

We will obtain coefficients [[r,s]] with [[ar+ds=1]]. Any solution of these two equations must then satisfy

[[c=(ar+ds)c=r(ac)+s(dc)=r(z+1)+sy.]]

This determines the candidate. To prove it works, the two target values must be compatible: [[ay=d(z+1)]]. Both identities will follow from the hypotheses.

Solving without division

A nonzero element of a Euclidean domain need not be invertible: [[2]] is nonzero in [[ℤ]], but [[1/2]] is not an integer. The combination [[r(z+1)+sy]] uses only ring operations. It also works when [[a=0]], provided [[ar+ds=1]].

The general lemma

In a commutative ring, suppose [[ar+ds=1]]. The equations [[ac=w]] and [[dc=y]] have a solution exactly when [[ay=dw]]. When they do, the solution is unique and equals [[rw+sy]].

Necessity follows from [[ay=a(dc)=d(ac)=dw]]. For sufficiency, put [[c=rw+sy]] and calculate:

[[ac=arw+s(ay)]]
Expand.
[[ =(ar+ds)w=w.]]
Use [[ay=dw]], then [[ar+ds=1]].
[[dc=r(dw)+dsy]]
Expand.
[[ =(ar+ds)y=y.]]
Use [[dw=ay]], then [[ar+ds=1]].

Uniqueness follows from the forced-value calculation above, with [[w]] in place of [[z+1]]. Thus changing the Bézout coefficients does not change [[c]] for fixed [[a,d,w,y]].

Proof

Put [[g=gcd(x,z)]]. If [[g=0]], then [[x=z=0]], and [[(a,d,b,c)=(1,y,0,1)]] has the required properties.

Now suppose [[g≠0]]. Since [[g]] divides [[x]] and [[z]], choose [[a,d]] with [[x=ga]] and [[z=gd]]. Choose Bézout coefficients [[r,s]] satisfying [[xr+zs=g]]. Substitution gives [[g(ar+ds)=g]], so cancellation yields

[[ar+ds=1.]]

The original equation gives [[g(ay)=g(d(z+1))]]. Cancelling [[g]] again yields

[[ay=d(z+1).]]

Apply the general lemma with [[w=z+1]]. Thus [[c=r(z+1)+sy]] satisfies [[ac=z+1]] and [[dc=y]]. Taking [[b=g]], we obtain

[[ab=x, dc=y, db=z, ac−db=(z+1)−z=1.]]
The nonzero hypothesis

The condition [[g≠0]] is used in the two cancellations. The general construction lemma does not use a gcd, cancellation, or an integral-domain assumption.

The product equation

The hypothesis [[xy=z(z+1)]] is necessary, not just an artifact of this proof. Any frame satisfies

[[xy=(ab)(dc)=(db)(ac)=z(z+1).]]

Exact integer arithmetic. The example does not replace the general proof.

Cantor’s theorem

For any set [[X]], no function [[f:X→𝒫(X)]] is surjective. Here [[𝒫(X)]] is the set of all subsets of [[X]].

Construction

To show that [[f]] misses a subset [[D]], it is enough to make [[D]] differ from [[f(a)]] for every [[a∈X]]. Use [[a]] itself as the witness of the difference: put [[a]] in [[D]] exactly when [[a]] is not in [[f(a)]]. This prescribes

[[D={x∈X:x∉f(x)}.]]

For every [[a]], the sets [[D]] and [[f(a)]] disagree about whether [[a]] belongs to them.

Proof

Suppose [[f]] were surjective. Then [[f(a)=D]] for some [[a∈X]]. By the definition of [[D]],

[[a∈D ⇔ a∉f(a) ⇔ a∉D.]]

This is impossible. Indeed, membership would imply nonmembership, so [[a∉D]]; but nonmembership would then imply membership. Hence [[f]] is not surjective.

The empty set

The construction does not assume [[X]] is nonempty. If it is empty, there is still a subset [[D=∅]], and there is no element that could map to it. In the proof, the assumed surjectivity itself supplies [[a]].

Finite illustration

Reversing a list twice

For any finite list [[L]],

[[rev(rev(L))=L.]]

Reduction

Induction removes the first element of a list. Reversal moves that element to the end, so the useful intermediate identity concerns concatenation:

[[rev(L⧺M)=rev(M)⧺rev(L).]]

Here [[⧺]] denotes concatenation. Reversal reverses each part and swaps the order of the parts.

Reversal of concatenation

Induct on [[L]]. The empty-list case is immediate. For a list beginning with [[a]], use the recursive rule [[rev(a::L)=rev(L)⧺[a]]]:

[[rev((a::L)⧺M)]]
[[ =rev(L⧺M)⧺[a]]]
The recursive rule.
[[ =(rev(M)⧺rev(L))⧺[a]]]
The induction hypothesis.
[[ =rev(M)⧺rev(a::L).]]
Associativity and the recursive rule.

Proof

Induct on [[L]]. The empty list is unchanged by reversal. For the induction step, assume [[rev(rev(L))=L]]. Then

[[rev(rev(a::L))]]
[[ =rev(rev(L)⧺[a])]]
Use the recursive rule.
[[ =[a]⧺rev(rev(L))]]
Reverse the concatenation.
[[ =[a]⧺L=a::L.]]
The induction hypothesis.

The original Lean proof instead uses a lemma about its accumulator-based implementation of reversal. Both arguments establish the same statement; the refactoring is a different proof, not a transcription of the original.
